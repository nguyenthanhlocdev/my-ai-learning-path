# Basic Python Notes

## Python là gì?

Python là một ngôn ngữ lập trình đa năng, dễ học và sử dụng. Nó được phát triển bởi Guido van Rossum và được phát hành lần đầu tiên vào năm 1991. Python có cú pháp đơn giản và rõ ràng, giúp người mới bắt đầu dễ dàng tiếp cận và học tập. Python được sử dụng rộng rãi trong nhiều lĩnh vực, bao gồm phát triển web, khoa học dữ liệu, trí tuệ nhân tạo, và tự động hóa.

## Tại sao nên học Python?

- Dễ học: Python có cú pháp đơn giản và dễ đọc, giúp người mới bắt đầu nhanh chóng nắm bắt được các khái niệm cơ bản của lập trình.
- Đa năng: Python có thể được sử dụng cho nhiều mục đích khác nhau, từ phát triển web đến khoa học dữ liệu và trí tuệ nhân tạo.
- Cộng đồng lớn: Python có một cộng đồng người dùng rộng lớn và năng động, cung cấp nhiều tài nguyên học tập và hỗ trợ.
- Thư viện phong phú: Python có một loạt các thư viện và framework mạnh mẽ, giúp bạn dễ dàng thực hiện các tác vụ phức tạp mà không cần phải viết mã từ đầu.
- Cơ hội nghề nghiệp: Python là một trong những ngôn ngữ lập trình phổ biến nhất trên thế giới, và có nhiều cơ hội nghề nghiệp cho những người biết sử dụng nó.

## What should a programming language provide?

Một ngôn ngữ lập trình nên cung cấp các kiểu dữ liệu cơ bản:

- **Numbers (Số):**
  - Ví dụ: 1, -2, -1.2, 2.7
- **Text (Văn bản):**
  - Ví dụ: a, b, c, Hello

Các kiểu dữ liệu này là nền tảng để xử lý thông tin trong lập trình.
